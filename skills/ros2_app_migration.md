# ROS2 App Migration Skill — Moved

This legacy single-file playbook is kept as a compatibility redirect.

Use the maintained standalone manual instead:

- `skills/migration/SKILL.md`

Why this file was demoted:

- The standalone manual is split into short-context tasks, templates,
  checklists, and references.
- It is the canonical guide for native ROS2 migration into DDS/ROS2-compatible
  and JSON/local application roles.
- It includes the OHOS / Route B cross-compile and target artifact audit gate.
- Keeping the old full playbook duplicated boundary claims and created drift risk.

Compatibility note:

- Existing links to `skills/ros2_app_migration.md` should continue to resolve to
  this redirect.
- New links should point directly to `skills/migration/SKILL.md`.
