# SDK Completeness Checklist

- [ ] SDK prefix exists:
  `test -d <sdk>`
- [ ] IBMW package config exists:
  `test -f <sdk>/lib/cmake/ibmw/ibmw-config.cmake`
- [ ] Helper CMake modules exist:
  `test -f <sdk>/cmake/IbmwHelpers.cmake`
- [ ] External consumer configures with SDK prefix:
  `cmake -S <consumer> -B <build> -DCMAKE_PREFIX_PATH=<sdk>`
- [ ] External consumer builds without IBMW source-tree paths.
- [ ] SDK profile is selected and recorded (`host_full`, `ohos_minimal`,
  `ohos_dds_ros2`, or another explicit profile).
- [ ] If the SDK is intended for multi-component development, the report states
  whether the universal full-dev SDK contract is validated. If not validated,
  the report says `build per capability set`.
- [ ] Consumer dependency closure is audited from the app artifacts, not inferred
  from the SDK prefix contents.
- [ ] A minimal/local consumer does not link/deploy DDS/FastDDS/ROS2 artifacts
  unless the app explicitly uses those components.
- [ ] No public header is installed under both `<sdk>/include/ibmw/<sub>/` and
  `<sdk>/include/ibmw/api/<sub>/`; `<sdk>/include/ibmw/api` should be absent
  unless a reviewed compatibility exception is documented.
- [ ] FastDDS/Fast-CDR provider is recorded.
- [ ] If cross SDK, target artifacts have expected architecture.
- [ ] If OHOS SDK, SDK was generated by cross-compiling IBMW with OHOS toolchain.
- [ ] If OHOS SDK, feature flags, sysroot, target ROS2/DDS provider, and target
  dependency prefixes match the product slice being built.
- [ ] If OHOS runtime is claimed, target `/data` run log contains startup PASS.
- [ ] If Route B/OHOS, `route_b_target_artifact_audit.json` is PASS.
- [ ] If `_deps`, `FetchContent`, or bundled Fast-CDR appears, the report records
  `reviewed exception`.
- [ ] Board runtime is marked separately from compile/audit evidence.
- [ ] DDS/ROS2 OHOS board runtime is marked `NOT VERIFIED` unless a DDS/ROS2
  `/data/<case>` target run log is attached.
