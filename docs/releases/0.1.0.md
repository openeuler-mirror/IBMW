# IBMW 0.1.0

Version 0.1.0 is the initial public version identified by the repository
`VERSION` file.

## Included public surface

- Modular C++20 runtime with executor, logging, configuration, parameter,
  transport, and RPC interfaces.
- Public C and C++ APIs, package ABI, type-support ABI, and extension API.
- Pluggable transport and service extension implementations included in the
  source tree and selected through CMake options.
- Example applications, `ibmw-template`, and the `ibmw-gen` project generator.
- DDS-based ROS2 interoperability documentation and interface-import workflows.
- Scoped AArch64 Linux and OHOS cross-compilation guidance.

## Getting started

Read the [User Guide](../guides/user-guide.md) and build with a documented CMake
preset. The `full` preset enables a broad source build, while individual
features still depend on their documented build options and external
dependencies.

## Compatibility and limitations

- C++20 is required.
- Optional extensions have distinct dependency and runtime requirements.
- The rcl/rclcpp-based ROS2 extension path is deprecated; DDS-only ROS2
  interoperability is the preferred documented direction.
- DDS-only ROS2 Action support is experimental and limited to the scope in the
  [adapter guide](../experimental/ros2-action-dds-only-adapter-guide.md).
- Cross-compilation results are limited to the lanes explicitly described in
  the [cross-compilation guide](../guides/cross-compilation.md); compile success
  is not a general board-runtime guarantee.
- Performance tables are reference observations, not guarantees for other
  hardware, kernels, payloads, or deployment topologies.

See [Compatibility Boundaries](../reference/compatibility.md),
[Security Policy](../../SECURITY.md), and [Support](../../SUPPORT.md) before
deploying or requesting assistance.
