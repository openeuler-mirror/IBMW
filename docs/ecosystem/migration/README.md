# Migration Resources

The public migration playbook lives under [`skills/migration/`](../../../skills/migration/).
It is organized for incremental use:

1. Start with the [decision tree](../../../skills/migration/00-decision-tree.md).
2. Read the [migration skill entry point](../../../skills/migration/SKILL.md).
3. Follow the numbered tasks in [`skills/migration/tasks/`](../../../skills/migration/tasks/).
4. Use the command and pitfall references in
   [`skills/migration/reference/`](../../../skills/migration/reference/).
5. Record results with the templates in
   [`skills/migration/templates/`](../../../skills/migration/templates/).

For interface-level conversion, also read the
[ROS2 Interface Import User Guide](../../guides/ros2-interface-import-user-guide.md).
For a concise application-oriented overview, see
[`skills/ros2_app_migration.md`](../../../skills/ros2_app_migration.md).
