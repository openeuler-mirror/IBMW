# IBMW Ecosystem Resources

IBMW includes public, task-oriented assets in `skills/` for teams integrating
the framework into existing products or preparing an SDK delivery. These files
are retained in their original locations so automation and established links
can continue to use them; this directory provides a human-facing entry point.

## Migration

Use the [Migration Resources](migration/README.md) when moving a ROS2
application through the documented IBMW migration routes. The material includes
a decision tree, task sequence, command references, checklists, and report
templates.

The standalone [ROS2 application migration guide](../../skills/ros2_app_migration.md)
provides a shorter overview for application teams.

## SDK delivery

Use the [SDK Resources](sdk/README.md) when packaging or validating a public
IBMW SDK. The assets cover delivery tasks, references, and checklists without
changing the SDK content itself.

These ecosystem assets supplement the [User Guide](../guides/user-guide.md),
[API Reference](../reference/api-reference.md), and
[Developer Guide](../contributing/developer-guide.md).
